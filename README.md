# BYXG

“新型多功能一体式草坪修剪护理机器人”项目资料归档仓库。

按比赛与文件类型分类整理：

- `01_挑战杯` / `02_互联网+` / `03_中国大学生计算机设计大赛` / `04_大创`：各赛事申报书、论文、计划书等文档
- `05_项目通用文档`：跨比赛通用的论文、期刊、作品集、展板、海报
- `06_PPT演示文稿`：演示文稿（按比赛分子目录）
- `07_图片`：实物照片、展板图、界面图、获奖截图等
- `08_视频`：项目素材与答辩视频
- `09_代码与工程`：上位机前端源码 + 串口屏工程
- `10_压缩包与源文件`：ZIP 原件与 PSD 源文件

逐件来源、目标路径与哈希对照见 `文件清单.csv`，整理说明见 `执行报告.md`。

> 注：超过 GitHub 100MB 单文件限制的大文件（部分大 PPT、视频、PSD）未纳入版本控制，仍保留在本地，清单见 `.gitignore`。
